알아 두실 것

  • 키는 이 브라우저와, 서버로 가는 요청 머리에만 있어요. 서버는 키를 저장하지도 기록하지도 않아요.
  • 「넣기」만 하면 이 창에만 있고, 창을 닫으면 사라져요. 「저장해 두기」를 켜면 이 브라우저에 남아요.
  • 비용은 키 주인에게 청구돼요. 질문 한 번에 약 30원(gpt-4o-mini)이고, 한 번에 약 100원이 넘으면 자동으로 멈춰요.
  • 「키 확인」은 모델 목록만 불러 보는 것이라 돈이 들지 않아요.
  • 키 만드는 곳: platform.openai.com → API keys. OpenAI API 는 미리 충전한 금액에서 빠지고, 자동 충전을 켜 두면 자동으로 결제돼요. 켜져 있는지 한번 확인하세요.
  • 남과 같이 쓰는 컴퓨터에서는 저장하지 마세요.
